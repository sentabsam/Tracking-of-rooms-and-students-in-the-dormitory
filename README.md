# RoomTrack
RoomTrack - консольное приложение для учета комнат и студентов, проживающих в общежитие. Система предназначена для хранения информации о комнатах, студентах и их заселении. Система должна позволять определить, какие комнаты свободны, а также какие студенты в них проживают.
## Возможности
В проекте реализованы следующие основные возможности:


	* добавление информации о студентах
	* заселение студентов в комнаты
	* выселение студентов
	* просмотр списка жильцов
	* проверка наличия свободных мест
	* поиск комнаты по номеру
